Panel de Neverland

Solo vos podés entrar: necesitás tu token personal de GitHub. Queda guardado únicamente en este navegador.

¿Cómo creo el token?
  1. Entrá a github.com/settings/personal-access-tokens/new
  2. Nombre: Panel Neverland. Vencimiento: el máximo que te deje.
  3. Resource owner: NeverlandPy.
  4. Repository access: Only select repositories → neverlandpy.github.io.
  5. Permissions → Repository permissions → Contents: Read and write.
  6. Generate token, copialo y pegalo arriba.
